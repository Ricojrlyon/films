activer le mode édition

Une seule fois, tu as besoin de coller ton token github et de choisir un code. Ensuite, pour modifier des films, tu n'auras qu'à entrer ton code.

colle ton token github. → comment en créer un
Créer un token GitHub :
  1. Va sur github.com/settings/personal-access-tokens/new
  2. Token name : films-admin
  3. Expiration : No expiration (pour ne plus jamais y revenir)
  4. Repository access → Only select repositories → coche films
  5. Permissions → Repository permissions → Contents → Read and write
  6. Generate token (en bas) → copie-le ici
tu auras besoin de ce code à chaque session pour activer l'édition. choisis quelque chose de simple à retenir mais que toi seul connais.
